# Family Recipes 👩🏻‍🍳

Веб-приложение для хранения и просмотра семейных рецептов.

Пользователь на данный момент может зарегистрироваться, войти в аккаунт, создавать рецепты и управлять своим профилем (выход из аккаунта и удаление). Карточки рецептов на главной странице - бутафория.
