# Family Recipes 👩🏻‍🍳

Веб-приложение для хранения и просмотра семейных рецептов.

Семейные рецепты: общий backend, веб-клиент и мобильное приложение.

---

## Что сделано 🍔

- Регистрация и вход (JWT)
- Профиль: выход, удаление аккаунта
- Создание рецепта
- Список рецептов с сервера на главной странице (только веб)
- Просмотр рецепта (только веб)

---
